联系开发者

请发送邮件至 wm88889@hotmail.com，我们通常会在两个工作日内回复。请注明 iPhone 型号、iOS 版本，以及“设置”页面底部显示的 Ippo Care 版本号，并说明你的操作、预期结果和实际情况。截图很有帮助，但请先遮挡健康细节。请勿发送 Apple 账户密码或 AI API 密钥。

哪些功能免费？完整版包含什么？

“今日”和“小城”永久免费。首次打开 App 后的 72 小时内，全部功能免费。之后，一次性购买完整版即可永久解锁“健康”“目标”“趋势”、助手及其他功能。它不是订阅，试用也绝不会自动扣费。

如何恢复购买？

请确认设备登录的是购买完整版时使用的 Apple 账户，然后打开“设置 › Ippo Care 完整版 › 恢复购买”。不需要 Ippo Care 账号。

如何申请退款？

App Store 的所有付款都由 Apple 处理，因此请在 reportaproblem.apple.com 或购买记录中向 Apple 申请退款。我们无法看到你的付款信息，也无法直接退款。

Apple 健康没有数据或数据不对

打开“健康”App › 共享 › App 与服务 › Ippo Care，确认已允许你需要的类别。然后打开 Ippo Care ›“健康数据源”并下拉刷新。Apple Watch 或 iPhone 的新读数可能需要几分钟才会进入 Apple 健康。Ippo Care 只读取 Apple 健康，绝不会修改你的健康记录。

设置 AI 助手

打开“设置 › AI 助手”，选择服务商，粘贴从该服务商网站获取的 API 密钥并选择模型。使用费用由服务商收取，而不是 Ippo Care。如遇到认证或额度错误，请在服务商网站上检查密钥、余额和模型名称。只有在“隐私与授权”中开启“AI 健康分析”后，助手才会读取你的健康记录。

导出、备份或删除数据

你的数据保存在 iPhone 上。请在“设置 › 隐私与授权 › 导出或删除数据”中保存副本或清除数据。由于没有 Ippo Care 云端副本，更换设备前请先导出或备份 iPhone。

Ippo Care 是医疗建议吗？

不是。Ippo Care 用于支持个人健康与健身，不诊断或治疗任何疾病。医疗问题请咨询合格的医疗专业人员，紧急情况请拨打当地急救电话。
