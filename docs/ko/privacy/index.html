요약

  • Ippo Care에는 개발자가 운영하는 계정 시스템이나 건강 데이터베이스가 없습니다. 프로필, 기록, 일지, 대화는 사용자의 iPhone에 저장됩니다.

1. 제공자 및 적용 범위

Ippo Care(이하 "앱")는 개인 개발자 Yusen Wang(이하 "당사")이 개발하고 제공합니다. 이 방침에서 설명하는 개인정보 처리의 책임자는 당사입니다. 연락처: wm88889@hotmail.com

이 방침은 iPhone용 Ippo Care와 이 개인정보 처리방침·약관·지원 페이지에 적용됩니다. 건강 데이터 출처, AI 제공업체, 앱에서 여는 웹사이트 등 사용자가 직접 선택해 연결하는 제3자 서비스에는 적용되지 않으며, 해당 서비스의 방침이 적용됩니다.

Ippo Care는 개인의 건강, 피트니스, 웰빙 정보를 기록하고 정리하며 이해하도록 돕는 앱입니다. 의료기기가 아니며 진단, 치료, 처방을 제공하지 않습니다.

2. 앱이 처리하는 정보

앱은 사용자의 기기에서 작동하므로 아래의 "처리"는 주로 iPhone에서 이루어집니다. 지원 이메일 등으로 사용자가 직접 보내지 않는 한, 개발자인 당사는 이 정보를 받지 않습니다.

  • 사용자가 입력한 프로필 정보: 키, 생년월일, 운동 심박수 구간과 근육 지도 체형에 쓰이는 성별, 단위 및 화면 설정, 목표와 진행 상황.
  • 사용자가 허용한 Apple 건강 데이터: 수면, 걸음 수, 활동 및 에너지, 심박수, 안정 시 심박수, 심박 변이도, 운동, 신체 측정값 등 사용자가 선택한 항목. 앱은 이 데이터를 읽기만 하며 Apple 건강에 쓰거나 수정하지 않습니다.
  • 사용자가 만든 기록: 식사, 보충제, 운동 종목·세트·무게, 신체 측정값, 메모, 첨부한 사진 및 기타 일지.
  • 어시스턴트 대화: 입력하거나 받아쓰기한 텍스트, 선택한 첨부 파일, 어시스턴트의 답변과 생성된 카드. 어시스턴트 메모리를 켠 경우, 이후 답변을 개인화하기 위해 저장되는 짧은 사실도 포함됩니다.
  • AI 설정: 입력한 제공업체, 서비스 주소, 모델 이름, 기능 설정, API 키.
  • 구입 및 체험 상태: 체험 기간 계산에 쓰이는 최초 실행 시각과 최근 사용 시각, Apple StoreKit이 제공하는 상품·거래·이용 권한 정보.
  • 선택 사항인 "Apple로 로그인": 사용하는 경우 Apple은 사용자의 선택에 따라 고정 식별자, 이름, 실제 또는 릴레이 이메일 주소를 제공할 수 있습니다. 기기 내 프로필 연결에만 사용하며 정식 버전 구입이나 복원에는 필요하지 않습니다.
  • 기기에 저장되는 기술 정보: 앱 설정, 캐시, 앱의 정상 작동을 위한 로컬 진단 로그. 이 정보는 당사로 자동 전송되지 않습니다.

3. 정보의 이용 목적

  • 매일의 상태, 추세, 차트, 목표, 배지, 그리고 실제 활동에 따라 성장하는 도시를 보여 주기 위해.
  • 사용자가 만든 기록을 저장·표시하고 편집, 내보내기, 삭제할 수 있게 하기 위해.
  • 질문에 대한 답변, 설명이나 사진을 바탕으로 한 식사·운동 기록, 계획 수립, 운동 설명 등 사용자가 시작한 어시스턴트 작업을 수행하기 위해.
  • 무료 체험을 계산하고 정식 버전을 확인하며 구입을 복원하기 위해.
  • 앱의 보안과 정상 작동을 유지하고, 사용자가 보낸 이메일에 답변하기 위해.
  • 당사는 사용자 정보를 광고, 마케팅 목적의 프로파일링, 데이터 거래, 당사 자체 AI 모델 학습에 사용하지 않습니다. 개인정보를 판매하거나 대여하지 않으며, 맞춤형 행태 광고를 위해 "공유"하지도 않습니다.

4. Apple 건강 및 시스템 권한

앱은 사용할 수 있는 항목에 대해 Apple 건강 읽기 권한을 요청합니다. 어떤 항목을 허용할지는 사용자가 결정하며, iOS는 사용자가 거부한 읽기 권한을 앱에 알려 주지 않으므로 누락된 데이터는 누락된 상태로 남습니다. 앱은 Apple 건강에 데이터를 쓰지 않습니다.

Apple HealthKit을 통해 얻은 데이터는 앱의 건강·피트니스 기능을 사용자에게 제공하는 데에만 사용합니다. 광고 등 데이터 마이닝 목적으로 사용하지 않고, 그러한 목적으로 제3자에게 공개하지 않으며, 판매하지 않고, 앱이 iCloud에 저장하지도 않습니다.

건강 데이터가 기기 밖으로 나가는 것은 "개인정보 보호 및 권한"에서 "AI 건강 분석"을 켜고 그것이 필요한 작업을 시작했을 때뿐이며, 이 경우에도 작업에 필요한 데이터만 사용자가 설정한 AI 제공업체로 전송합니다(제5조 참조).

카메라, 사진 보관함, 마이크, 음성 인식은 해당 기능을 사용할 때만 권한을 요청합니다. 각 권한은 iOS 설정에서, 건강 권한은 건강 앱의 공유 › 앱 및 서비스 › Ippo Care에서 언제든지 변경할 수 있습니다. 권한을 철회하면 이후의 읽기가 중단되지만 앱에 이미 저장된 사본은 삭제되지 않으므로, 앱의 데이터 관리에서 삭제해 주세요.

5. 선택형 AI 기능과 제3자 수신자

어시스턴트는 사용자가 선택한 AI 제공업체와 사용자가 제공한 API 키로만 작동합니다. Ippo Care는 자체 모델 서비스를 운영하지 않고 모델 이용권을 재판매하지 않으며, 정식 버전에는 AI 이용 요금이 포함되지 않습니다. 요금은 제공업체가 자체 약관에 따라 사용자에게 직접 청구합니다.

어시스턴트 작업을 시작하면 앱은 해당 작업에 필요한 것, 즉 메시지, 관련 대화 맥락, 선택한 첨부 파일, 그리고 "AI 건강 분석"을 켠 경우에만 작업에 필요한 건강 기록을 제공업체로 전송합니다. 제공업체는 IP 주소 등 인터넷 요청에 필요한 기술 데이터도 받습니다.

현재 지원하는 제공업체는 OpenAI, DeepSeek, Anthropic(Claude), Alibaba Cloud Qwen, Google Gemini, xAI, OpenRouter, SiliconFlow, Moonshot Kimi, Zhipu, MiniMax, Volcengine Ark 및 사용자가 입력한 호환 주소입니다. 작업별로 설정한 제공업체만 해당 작업의 요청을 받습니다. 설정에 따라 대화, 이미지 생성, 동영상 생성, 온라인 음성 등 작업마다 다른 제공업체를 사용할 수 있습니다.

웹 검색을 켜면 검색어와 읽을 웹페이지 주소가 설정한 검색 서비스나 제공업체로 전송됩니다. 일반적인 문헌 검색은 PubMed / NCBI로 전송될 수 있습니다. 검색어는 일반적인 단어로 구성되며, 앱은 어시스턴트가 사용자의 이름이나 개인 기록을 포함하지 않도록 지시합니다.

온라인 음성이나 이미지·동영상 생성 서비스를 선택하면 읽을 텍스트나 생성에 필요한 프롬프트와 자료가 해당 서비스로 전송됩니다. 기본 읽어 주기는 기기 내 Apple 시스템 음성을 사용합니다.

데이터를 어디서 처리하고, 얼마나 보관하며, 모델 학습에 사용하는지는 각 제공업체가 결정합니다. 일부 제공업체는 사용자의 국가나 지역 밖에서 데이터를 처리합니다. 선택한 제공업체의 개인정보 처리방침을 확인해 주세요. AI를 끄거나 제공업체를 삭제하면 이후 요청은 중단되지만, 제공업체가 이미 보관한 사본은 삭제되지 않으므로 해당 제공업체에 삭제를 요청해 주세요.

API 키는 iOS 키체인에 저장되고, 인증을 위해 해당 키의 제공업체에만 전송되며, 내보내기 파일이나 대화 내용에 포함되지 않습니다.

6. 저장 위치와 보호 조치

프로필, 기록, 일지, 대화, 첨부 파일은 iPhone의 앱 전용 저장 공간에 저장됩니다. 앱은 로컬 데이터베이스를 암호화하고, 데이터베이스 키와 API 키를 iOS 키체인에 보관하며, iOS 데이터 보호 기능을 이용합니다. iCloud나 컴퓨터로 기기를 백업하면 백업 설정과 Apple 약관에 따라 앱 데이터가 포함될 수 있습니다.

완벽하게 안전한 저장·전송 방법은 없습니다. 기기에 암호를 설정하고, 내보낸 파일을 안전하게 보관하며, 신뢰할 수 있는 서비스에만 데이터를 보내 주세요.

당사는 사용자의 건강 기록을 받는 서버를 운영하지 않습니다. 위젯과 실시간 현황은 사용자가 표시하도록 선택한 정보를 홈 화면이나 잠금 화면에 보여 주므로, 기기에 접근할 수 있는 사람이 볼 수 있습니다.

7. 보관 기간

  • 프로필, 기록, 일지, 대화: 앱에서 삭제하거나 앱을 삭제할 때까지.
  • 어시스턴트 메모리: 해당 항목을 삭제하거나, 기능을 끄고 지우거나, 앱을 삭제할 때까지.
  • 내보내기 파일: 앱 내 임시 내보내기 파일은 약 10분 후 자동 삭제됩니다. 다른 곳에 저장하거나 공유한 사본은 사용자가 관리합니다.
  • 키체인의 체험 시각 기록: 무료 체험이 다시 시작되지 않도록 앱 삭제 후에도 남을 수 있으며, 건강 정보는 포함하지 않습니다.
  • 구입 기록: Apple이 자체 정책에 따라 보관합니다.
  • 지원 이메일: 요청과 후속 조치에 필요한 기간 동안만 보관하며, 법률이 더 긴 기간을 요구하지 않는 한 일반적으로 2년을 넘지 않습니다.

8. 사용자의 선택과 권리

  • 열람 및 내보내기: 설정 › 개인정보 보호 및 권한 › 데이터 내보내기 또는 삭제에서 기록 사본을 만들어 저장하거나 공유할 수 있습니다.
  • 정정: 프로필, 기록, 목표를 앱에서 직접 편집할 수 있습니다.
  • 삭제: 개별 기록 또는 앱의 모든 데이터를 앱에서 삭제할 수 있습니다. 앱에서 삭제해도 Apple 건강의 원본 데이터나 AI 제공업체가 보관한 사본은 삭제되지 않습니다.
  • 동의 철회: 언제든지 "AI 건강 분석"을 끄거나, AI 제공업체와 키를 삭제하거나, 시스템 권한을 철회할 수 있습니다. 철회 전에 이루어진 처리에는 영향을 주지 않습니다.

  • 거주 지역의 개인정보 보호 감독기관에 민원을 제기할 수도 있습니다.
