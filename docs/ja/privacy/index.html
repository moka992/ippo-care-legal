概要

  • Ippo Care には開発者が運営するアカウントシステムも健康データベースもありません。プロフィール、記録、日記、会話はあなたの iPhone に保存されます。

  • Apple ヘルスケアのデータは許可を得た範囲でのみ読み取り、広告やマーケティングには一切使用せず、販売や貸与もしません。

  • アプリには広告、第三者の分析ツールやトラッキング SDK は含まれておらず、他社のアプリや Web サイトをまたいだトラッキングも行いません。

  • AI は任意の機能です。あなた自身の API キーで AI プロバイダを設定し、それを必要とする作業を始めたときにのみ、関連する内容がそのプロバイダに送信されます。

  • データはいつでもアプリ内で書き出しまたは削除でき、許可は iOS の設定またはヘルスケア App で取り消せます。

01提供者と本ポリシーの適用範囲

Ippo Care（以下「本アプリ」）は、個人開発者 Yusen Wang（以下「当方」）が開発・提供しています。本ポリシーに記載する取り扱いの責任者は当方です。連絡先：wm88889@hotmail.com

本ポリシーは iPhone 版 Ippo Care と、これらのプライバシー・規約・サポートページに適用されます。ヘルスケアのデータソース、AI プロバイダ、本アプリから開く Web サイトなど、あなたが自ら選んで接続する第三者サービスには適用されず、それぞれのポリシーが適用されます。

Ippo Care は、個人の健康・フィットネス・ウェルビーイングに関する情報の記録、整理、理解を助けるアプリです。医療機器ではなく、診断、治療、処方は行いません。

02本アプリが扱う情報

本アプリはあなたのデバイス上で動作するため、以下の「取り扱い」は主に iPhone 上で行われます。サポートメールなどであなたが自ら送らない限り、開発者である当方がこれらの情報を受け取ることはありません。

  • 入力したプロフィール情報：身長、生年月日、トレーニング心拍ゾーンと筋肉マップの体型に使う性別、単位や外観の設定、目標と進捗。
  • 許可した Apple ヘルスケアのデータ：睡眠、歩数、アクティビティとエネルギー、心拍数、安静時心拍数、心拍変動、ワークアウト、身体測定など、あなたが選んだカテゴリ。本アプリはこれらを読み取るだけで、ヘルスケアへの書き込みや変更は行いません。
  • 作成した記録：食事、サプリメント、ワークアウトの種目・セット・重量、身体測定、メモ、添付した写真、その他の日記。
  • アシスタントとの会話：入力または音声入力したテキスト、選んだ添付ファイル、アシスタントの返信と生成カード。アシスタントのメモリーを有効にした場合は、後の返信を個人に合わせるために保存される短い事実も含みます。
  • AI の設定：入力したプロバイダ、サービスアドレス、モデル名、機能のオン・オフ、API キー。
  • 購入と無料体験の状態：体験期間の計算に使う体験開始日時（体験を始めた場合）と最終使用日時、および Apple StoreKit が返す商品・取引・利用権の情報。
  • 任意の「Apple でサインイン」：使用した場合、Apple はあなたの選択に応じて固定の識別子、氏名、実際のメールアドレスまたはリレー用アドレスを提供することがあります。本機のプロフィールとの関連付けにのみ使用し、完全版の購入や復元には不要です。
  • デバイスに保存される技術情報：アプリの設定、キャッシュ、正常に動作させるためのローカル診断ログ。これらが自動的に当方へ送信されることはありません。

03情報の利用目的

  • 毎日の状態、トレンド、グラフ、目標、バッジ、そして実際の活動に合わせて育つ「街」を表示するため。
  • 作成した記録を保存・表示し、編集、書き出し、削除できるようにするため。
  • 質問への回答、説明や写真からの食事・ワークアウトの記録、計画作成、種目の解説など、あなたが始めたアシスタントの作業を行うため。
  • 無料体験の計算、完全版の確認、購入の復元のため。
  • 本アプリの安全と正常な動作を保ち、いただいたメールに返信するため。
  • 広告、マーケティング目的のプロファイリング、データの売買、当方独自の AI モデルの学習には使用しません。個人情報を販売・貸与せず、クロスコンテキスト行動広告のために「共有」することもありません。

04Apple ヘルスケアとシステムの許可

本アプリは、利用できるカテゴリについて Apple ヘルスケアの読み取り許可を求めます。どのカテゴリを許可するかはあなたが決め、iOS はどの読み取り許可が拒否されたかを本アプリに伝えません。不足しているデータは不足したままとなります。本アプリはヘルスケアに書き込みません。

Apple HealthKit から取得したデータは、本アプリの健康・フィットネス機能をあなたに提供するためだけに使用します。広告などのデータマイニング目的には使用せず、その目的で第三者に開示せず、販売せず、本アプリが iCloud に保存することもありません。

健康データがデバイスの外に出るのは、「プライバシーと許可」で「AI健康分析」をオンにし、それを必要とする作業を始めたときだけです。その場合も、作業に必要なデータのみを設定した AI プロバイダに送信します（第 5 条）。

カメラ、写真ライブラリ、マイク、音声認識は、それを必要とする機能を使うときにのみ許可を求めます。各許可は iOS の設定で、ヘルスケアの許可はヘルスケア App の「共有」›「App とサービス」› Ippo Care でいつでも変更できます。取り消すと以後の読み取りは止まりますが、本アプリにすでに保存されたコピーは削除されないため、アプリのデータ管理で削除してください。

05任意の AI 機能と第三者の受領者

アシスタントは、あなたが選んだ AI プロバイダとあなたが提供する API キーでのみ動作します。Ippo Care は独自のモデルサービスを運営せず、モデルの利用枠を再販せず、完全版に AI の利用料金は含まれません。料金はプロバイダが自らの規約に基づいてあなたに直接請求します。

アシスタントの作業を始めると、本アプリはその作業に必要なもの、すなわちメッセージ、関連する会話の文脈、選んだ添付ファイル、そして「AI健康分析」がオンの場合に限り作業に必要な健康記録をプロバイダに送信します。プロバイダは、IP アドレスなどインターネット通信に必要な技術データも受け取ります。

現在対応しているプロバイダは、OpenAI、DeepSeek、Anthropic（Claude）、Alibaba Cloud Qwen、Google Gemini、xAI、OpenRouter、SiliconFlow、Moonshot Kimi、Zhipu、MiniMax、Volcengine Ark、およびあなたが入力した互換アドレスです。作業ごとに設定したプロバイダだけがその作業のリクエストを受け取ります。設定によっては、会話、画像生成、動画生成、オンライン読み上げなど作業ごとに異なるプロバイダを使えます。

Web 検索をオンにすると、検索語と読み取るページのアドレスが設定した検索サービスまたはプロバイダに送信されます。一般的な文献検索は PubMed / NCBI に送信されることがあります。検索語は一般的な語で構成され、本アプリはアシスタントにあなたの氏名や個人の記録を含めないよう指示しています。

オンラインの読み上げ音声や画像・動画の生成サービスを選んだ場合は、読み上げるテキストや生成に必要なプロンプト・素材がそのサービスに送信されます。標準の読み上げは Apple のデバイス上のシステム音声を使用します。

どこでデータを処理し、どのくらい保存し、モデルの学習に使うかどうかは各プロバイダが決めます。あなたの国や地域の外でデータを処理するプロバイダもあります。選んだプロバイダのプライバシーポリシーをご確認ください。AI をオフにしたりプロバイダを削除したりすると以後のリクエストは止まりますが、プロバイダがすでに保持しているコピーは削除されないため、削除はプロバイダに依頼してください。

API キーは iOS のキーチェーンに保存され、認証のためにそのキーのプロバイダにのみ送信されます。書き出しファイルに含まれることも、会話の内容に入ることもありません。

06保存場所と保護対策

プロフィール、記録、日記、会話、添付ファイルは、iPhone 上の本アプリ専用の保存領域に保存されます。本アプリはローカルのデータベースを暗号化し、データベースの鍵と API キーを iOS のキーチェーンに保管し、iOS のデータ保護を利用しています。iCloud やコンピュータでのデバイスのバックアップには、バックアップ設定と Apple の規約に従って本アプリのデータが含まれることがあります。

完全に安全な保存・通信方法はありません。デバイスにパスコードを設定し、書き出したファイルを安全に保管し、信頼できるサービスにのみデータを送ってください。

当方は、あなたの健康記録を受け取るサーバーを運営していません。ウィジェットとライブアクティビティは、表示を選んだ情報をホーム画面やロック画面に表示するため、デバイスを手に取れる人に見られる可能性があります。

07保存期間

  • プロフィール、記録、日記、会話：アプリ内で削除するか、アプリを削除するまで。
  • アシスタントのメモリー：その項目を削除するか、機能をオフにして消去するか、アプリを削除するまで。
  • 書き出しファイル：アプリ内の一時的な書き出しファイルは約 10 分後に自動で消去されます。別の場所に保存・共有したコピーはあなたの管理となります。
  • キーチェーンの体験期間のタイムスタンプ：無料体験の再開始を防ぐため、アプリ削除後も残ることがあります。健康情報は含みません。
  • 購入記録：Apple が自らのポリシーに基づいて保存します。
  • サポートのメール：ご依頼とその後の対応に必要な期間だけ保存し、法律でより長い期間が求められる場合を除き、通常 2 年を超えません。

08あなたの選択と権利

  • 開示と書き出し：「設定」›「プライバシーと許可」›「データの書き出しまたは削除」で記録のコピーを作成し、保存や共有ができます。
  • 訂正：プロフィール、記録、目標はアプリ内で直接編集できます。
  • 削除：個々の記録、または本アプリのすべてのデータをアプリ内で削除できます。アプリ内で削除しても、ヘルスケアの元データや AI プロバイダが保持するコピーは削除されません。
  • 同意の撤回：「AI健康分析」をオフにする、AI プロバイダとキーを削除する、システムの許可を取り消す、といったことがいつでもできます。撤回前に行われた取り扱いには影響しません。
  • お問い合わせ：質問、ご依頼、苦情は wm88889@hotmail.com までお送りください。当方のサーバーにはあなたのアプリのデータがないため、ほとんどのご依頼はアプリ内で直接対応でき、その方法をご案内します。最初のメールには健康記録、身分証、パスワード、API キーを送らないでください。
  • お住まいの地域の個人情報保護機関に苦情を申し立てることもできます。

09地域ごとの補足

  • 英国および同様の法律：当方は、ご要望の本アプリを提供するため（契約）、健康データおよび AI プロバイダへの送信についてのあなたの明示的な同意、ならびに本アプリの安全を保つ正当な利益に基づいてデータを取り扱います。あなたには開示、訂正、消去、制限、データポータビリティ、異議申し立ての権利があり、情報コミッショナー事務局（ICO）に苦情を申し立てることができます。
  • 米国（カリフォルニア州など個人情報保護法のある州を含む）：当方は個人情報を販売せず、クロスコンテキスト行動広告のために共有せず、センシティブな個人情報を使ってあなたの特性を推測しません。個人情報の開示、削除、訂正を求めることができ、権利を行使したことを理由に差別的な扱いをすることはありません。提供された消費者健康データは、ご要望の機能の提供にのみ使用します。
  • 日本（個人情報保護法）：健康情報は要配慮個人情報にあたり、あなたの同意を得た場合にのみ取得します。日本国外にある AI プロバイダを選んだ場合、データはあなたの指示によりそのプロバイダに提供されます。所在国や保護措置についてはそのプロバイダのポリシーをご確認ください。
  • 韓国（個人情報保護法）：健康情報は敏感情報にあたり、あなたの個別の同意がある場合にのみ取り扱います。データが国外に送られるのは、作業を始めたときに、あなたが選んだ AI プロバイダに対してのみであり、AI をオフにすればこれを止められます。
  • 台湾、香港、マカオ、シンガポール、マレーシア：本ポリシーに記載した目的のためにのみ個人データを収集し、必要な期間だけ保存し、連絡先に送られた開示・訂正の依頼に対応します。
  • カナダ、オーストラリア、ニュージーランド：当方が保有するあなたの個人情報の開示と訂正を求め、関係するプライバシーコミッショナーに苦情を申し立てることができます。
  • 確認できたご依頼には 30 日以内に回答するよう努めます。現地の法律でより短い期限が定められている場合はそれに従います。

10未成年者

Ippo Care は一般向けの健康・フィットネスアプリであり、13 歳未満（またはお住まいの国の最低年齢未満）の子どもを対象としていません。未成年者は保護者の関与のもとでご利用ください。AI プロバイダが独自の最低年齢を定めている場合があります。

子どもが当方に個人情報を提供したと思われる場合はご連絡ください。削除を含む適切な措置を講じます。

12本ポリシーの変更

本アプリの機能やデータの取り扱いが変わったときは本ポリシーを更新します。ページ上部の日付が最新版を示し、すべての変更履歴はこれらのページを公開するリポジトリで公開されています。データの使われ方に重大な影響を与える変更の場合は、アプリ内でお知らせし、必要に応じて改めて同意を求めます。
