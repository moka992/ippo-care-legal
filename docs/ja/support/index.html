よくある質問

無料で使える機能と、完全版に含まれるもの

「今日」と「街」はずっと無料です。初めてアプリを開いてから 72 時間は、すべての機能を無料で使えます。その後は、一度きりの完全版の購入で「健康」「目標」「トレンド」、アシスタントなどが永続的に解放されます。サブスクリプションではなく、体験期間後に自動で課金されることもありません。

購入を復元するには

完全版を購入した Apple アカウントでデバイスにサインインしていることを確認し、「設定」›「Ippo Care 完全版」›「購入を復元」を開いてください。Ippo Care のアカウントは必要ありません。

返金を受けるには

App Store での支払いはすべて Apple が処理するため、返金は reportaproblem.apple.com または購入履歴から Apple に申請してください。当方は支払い情報を見ることも、直接返金することもできません。

ヘルスケアのデータが表示されない・正しくない

ヘルスケア App の「共有」›「App とサービス」› Ippo Care を開き、必要なカテゴリが許可されているか確認してください。次に Ippo Care の「健康データソース」を開き、下に引いて更新します。Apple Watch や iPhone の新しい測定値がヘルスケアに届くまで数分かかることがあります。Ippo Care はヘルスケアを読み取るだけで、記録を変更することはありません。

AI アシスタントの設定

「設定」›「AIアシスタント」を開き、プロバイダを選び、そのプロバイダの Web サイトで取得した API キーを貼り付けて、モデルを選んでください。料金は Ippo Care ではなくプロバイダが請求します。認証や利用上限のエラーが出る場合は、プロバイダの Web サイトでキー、残高、モデル名を確認してください。アシスタントが健康記録を読むのは、「プライバシーと許可」で「AI健康分析」をオンにした場合だけです。

データの書き出し・バックアップ・削除

データは iPhone に保存されています。「設定」›「プライバシーと許可」›「データの書き出しまたは削除」でコピーを保存したり消去したりできます。Ippo Care のクラウド上のコピーはないため、機種変更の前には書き出すか iPhone をバックアップしてください。

Ippo Care は医療上の助言ですか？

いいえ。Ippo Care は個人の健康管理とフィットネスを支えるもので、病気の診断や治療は行いません。医療に関する質問は資格ある医療専門家に、緊急時は地域の緊急通報番号にご連絡ください。

ポリシー

プライバシーポリシーIppo Care が何を扱い、どこに保存し、誰に送るのか。そして、あなたがどう管理できるのか。利用規約Ippo Care、無料機能、一度きりの完全版購入、そして任意の AI アシスタントを利用するためのルールです。Apple 標準使用許諾契約このページ上部のリンクからプライバシーポリシーと利用規約をお読みください。購入には Apple 標準使用許諾契約も適用されます。
